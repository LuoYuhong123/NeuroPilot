# Spine Demo Dataset

Download the spine demo movie from the GitHub Release asset:

```text
https://github.com/LuoYuhong123/NeuroPilot/releases/download/v0.1.0/demo_data_spine.tiff
```

Save it locally as:

```text
demo_data/spine/demo_data_spine.tiff
```

The TIFF payload is intentionally not tracked in normal git history because it
is larger than GitHub's regular file-size limit.
