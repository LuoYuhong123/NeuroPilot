# Spine Demo Dataset

Download the spine demo movie from the GitHub Release asset:

```text
https://github.com/LuoYuhong123/NeuroPilot/releases/download/v0.1.0/ju2df_5day_freemoving-male1-5day-image-pain.0.tif
```

Save it locally as:

```text
demo_data/spine/ju2df_5day_freemoving-male1-5day-image-pain 0.tif
```

The TIFF payload is intentionally not tracked in normal git history because it
is larger than GitHub's regular file-size limit.
